# 录入资料与学生提醒的衔接

家长已确认：学生点开提醒就记录提示后通过，P值映射以后再定。入库Skill不要因这种记录自动改P2或重新分类，也不要把新收的材料反写成过去任务已显示过的答案。

题干、原作答、参考答案、参考分析继续分别用prompt/figure/work/answer/analysis保存。提醒优先显示work影像，没有时显示已存题面；只显示已有参考答案，AI答案须先经家长确认，不现场生成。新任务发布时冻结资料，新增或修改答案只影响后续任务；旧任务使用已有快照，不为了补显示而改写历史。

学生点开提醒后，同库student_hint:<task_item_id>保存recorded_result=hint及关联事件。该记录由正式学生动作产生；智能体整理或预览入库时不能替学生调用学生提醒接口，因为调用就会记录提示后通过。不要把“想看原题或答案”当成代学生点提醒的授权。查阅资料用家长入口；测试只用独立轻量样本。

阅读理解继续只保存分类与智能体分析，不上传原题/原文/题图/答案，不经提醒路径绕过。强化题的原错题关联必须来自同一权威库的同科普通错题号，不复制另一套主库。重温阶段与日期交给重温Skill和家长反馈，录入Skill不自行推进。
