# 默认图片处理

入库Skill 1.9.1-rc.1。此规则适用于普通错题照片加工，不改变统一题号、来源、P值、重温或家长确认边界。

## 每次的默认动作

1. 保留原文件和SHA-256，另建处理副本。优先复用宿主已执行的可靠处理回执；核对原图/副本哈希及用途，不反复有损压缩。
2. 尊重EXIF方向；按可辨文字方向纠正横放/倒置，再纠正轻微歪斜。没有可靠文字依据时不猜方向，保留原图并列待核。
3. 仅裁外围空白，保留安全边距。完整条件、题号、小问、选项、指数、单位和必要图形不得丢失；其他题、手写作答或批改不是几何裁边可以自动删除的“无用内容”。含多题时先保留来源，按既有题号加工，不擅造题号。
4. 处理副本最大边3200像素，JPEG质量0.90，小图不放大。单张输入最多16MB、4000万像素。比较处理前后内容；压缩不清、边缘被截或必要图不完整则保留原图、列待补，不伪装合格。
5. 页面查看使用另建的适中缩略图：最大960×720、JPEG质量0.82，常用300×180显示框，可点击原图放大。缩略图只供浏览，不能替代识别/练习用清晰题图。
6. 再按主文件恢复完整无答案练习题。原错图、学生作答、答案和分析分别保留，不通过自动裁边覆盖原资料。缺少干净几何图时列待补，不能只写“见原图”。答案分析待家长核实，保持origin=agent、confirmed=false。

## 可独立调用的工具

```sh
python3 scripts/photo_prepare.py --input /path/photo.jpg --output /path/photo-prepared.jpg --report /path/photo-prepared.json
```

三个路径分别保存；输出和回执已存在时拒绝覆盖。成功回执包含原图与副本SHA-256、旋转和纠偏角度、裁边标记、尺寸、原图保留及未用网络的事实。失败不写库，不借此自动上传给其他服务。

Python入口本身只用标准库。自动几何处理当前依赖macOS Vision/CoreImage与swiftc；随Skill携带assets/photo_prepare.swift，首次在本机编译并缓存。无需模型API、新账号或付费OCR。其他平台或只读云端无法执行该工具时，宿主可预处理后附带回执；没有能力时列缺口，不编造成功。不能把源码链接当作已运行工具。

## 工作台内Codex模式

上传时与后台整理前，工作台调用本Skill同一脚本；后台只在任务目录生成副本，不改原资产。Codex收到整理后的附件、原资产关联及处理回执，同时加载本文件。Codex的看图回合不执行工具，不能在回复中假装运行脚本；宿主负责实际执行，模型负责检查题面完整性与标准包内容。页面缩略图由宿主按本规则生成。

阅读理解仍只留分类与分析摘要，不上传阅读原题给后续重温；强化题仍走专门来源审核。自动处理不是写库授权或学习结果。
