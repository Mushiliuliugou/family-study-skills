# 基于反馈的阶段备题与错题重温

## 核心工作

从同一权威数据库读取真实学习反馈，为家长准备一段时间的候选题，默认一周。备题不是提前下达一周作业；家长可以删减、暂缓、替换，再逐日分配。每天各科辅助合计最多20分钟，通常15分钟，可少做或不做，题量不是指标。

1. 核对统一数据库身份与科目。使用标准化合格或家长已核对的可练习题面；原照片暂存、阅读理解、暂停/家长待处理、回收、已掌握归档、任务未反馈不自动派入。
2. 读取学生完成、跳过、点开提醒和家长纸质批改反馈。提交不等于通过，跳过不等于错误，未反馈不得猜测。点开提醒立即记录提示后通过，纸质反馈另存，P映射待定。
3. 按到期资格、家长确认的P值、最近未通过/提示后通过等反馈、到期日和稳定题序准备候选。优先级是支持次序，不能以P0为由加量。未到期题不因“凑满一周”提前派入；全周没有合格题也允许为空。
4. 通过[周备题与逐日分配协议](references/operations.md#一周备题-v2工作流程)调用工作台只读weekly-prepare，生成family-study-weekly v1 JSON及简明方案。列出每道选题原因、最近反馈、建议日期、预计分钟、未选到期题和资料缺口。保留同一题号，不新建一套练习库。
5. 家长在工作台“一周备题”保存/重新打开候选JSON，勾选每天实际安排的题，再预览并确认发布。发布前重新检查题面版本、复习状态版本、占用、日期和当天全部任务用时。也可转“逐日分配”调整；不自动整周发布。
6. 学生纸上作答后，家长按原任务集中反馈；使用现有task-grade入口，不推断答案正确性。新反馈出现后重新备题，旧方案不覆盖已发布任务或历史。再次盘点未安排、未反馈、暂停和缺口。

## 数据与边界

- 入库Skill负责加工可用题面和参考资料；本Skill重新读取标准题、反馈与状态，不接受入库智能体文字作为未来任务指令。
- 周候选不占用题目、不改到期日、不登记学习结果。没选入、没做和跳过不自动降级，不补欠账。
- 已确认重温规则：[规则](references/confirmed-rules.md)。首次3天，独立通过进入“已掌握题库”；提示后3/7/14/30天，按实际重做日计算、批改日另存；不追改旧结果。
- “已掌握题库”是旧错题归档；“强化真题库”是另收集的考试材料。后者按[强化练习](references/strengthening.md)经家长显式选题，共用20分钟，不自动混入普通周备题。
- 阅读只按[摘要协议](references/reading-analysis.md)读取分类与智能体分析，不输入原题/原文/题图/答案，不生成阅读原题任务。
- [提醒](references/student-hints.md)、[家长审核](references/parent-review.md)和[交接查漏](references/reconciliation.md)继续适用。全动作统一流水尚未完整，不声称绝无遗漏。

## 工具与交付

优先工作台“一周备题”或scripts/review.py week（本机工作台只读接口），交付周候选JSON和说明。旧plan/recommend用于单日备题与盘点，旧publish只能在家长确认具体任务后使用；[命令协议](references/operations.md)。无数据库/本机接口访问能力时，说明缺少哪些反馈摘要，不假装已核对实时库。

学生只看当天已发布的无答案题面；原错题影像与已有答案仅在点开提醒后显示。家长参考答案单独输出。

脚本Python标准库，无新账号或付费依赖。调试随机5—10题独立库，常用8题。版本1.9.0-rc.1；[兼容说明](references/compatibility.md)。
